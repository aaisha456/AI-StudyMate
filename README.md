 How to Run the AI StudyMate Project:
1. Open the AI StudyMate project folder in Visual Studio Code.
2. Open the terminal and start the Flask backend:
 cd backend
..\venv\Scripts\Activate.ps1
python app.py
3. Keep the terminal running. The backend will run at http://127.0.0.1:5000.
4. Open the frontend folder in VS Code.
5. Right-click index.html and select Open with Live Server.
6. The website will open in your browser. Register or log in to access the AI StudyMate features.

Project Description

AI StudyMate is a web-based learning and revision system designed to help students understand concepts and improve their academic performance. It provides features such as study material management, AI-based explanations, Teach Me Back analysis, flashcards, MCQ practice, short-answer questions, progress tracking, and smart revision. The system uses rule-based logic to support learning and identify areas that need improvement. It aims to make studying more interactive, organized, and effective.
